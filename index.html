My long-term question is how to build intelligent, minimally invasive interfaces that can sense a neural state and decide when intervention is warranted. This project isolates the sensing decision: how much seizure sensitivity survives when we constrain false positives, and does the answer change from person to person?

The KNOT Lab showed that a 90-second snapshot of background hippocampal functional connectivity can forecast seizure likelihood over the next 24 hours as accurately as a model that requires a 4–45 day intracranial epileptiform-activity cycle. I re-analyzed the lab's public participant-level ROC data as an operating-point problem rather than a single cohort-average score.

The question

Decision-facing analysis

At the same false-positive-rate budget, which model preserves more true-positive sensitivity for each participant?

AUC is useful for showing overall discrimination, but an implanted or wearable interface eventually needs an operating point. False-positive rate does not equal the number of daily alerts, yet it is the decision quantity available in the public data and provides a transparent first constraint on unnecessary interventions.

1. The cohort mean hides model switching

The published FC and IEA-cycle models are similar at the cohort level. The participant-level comparison is more informative: some participants sit far above the equality line and favor momentary FC, while others favor the long-baseline cycle model.

What this lets the lab test next

The analysis turns a cohort-level equivalence result into a patient-level model-selection hypothesis. Participants with a large FC advantage are candidates for short-history sensing, while those favoring IEA cycles may need longer temporal context or a fused estimator.

  • Pre-register a patient-specific FPR budget and test whether its operating point remains stable over time.
  • Use longitudinal drift to decide when a forecast model should recalibrate rather than when stimulation should fire.
  • Combine momentary network connectivity with slow cycle phase only where the participant-level gain justifies the extra sensing history.

Where I add value

My computational neuroscience work uses simulation and model comparison to connect neural dynamics to intervention choices. Here I contribute a transparent patient-level robustness analysis and a reproducible interface that makes the state-estimation tradeoff inspectable. This does not claim hands-on RNS acquisition or clinical deployment experience; it shows how I would reason about the computational layer between sensing and modulation.

Methods and reproducibility

The page loads the KNOT Lab's source CSV files directly from repository commit fea1a8d. It reproduces the participant-level FC and IEA-cycle AUC comparison from Figure 2c. For the new operating-point view, ROC points from Extended Data Figure 7d are grouped by participant and model, duplicate FPR values retain the maximum TPR, TPR is made non-decreasing with cumulative maxima, and a selected FPR is linearly interpolated between adjacent points.

Limits
  • Retrospective cohort of 15 adults with bitemporal epilepsy; generalization beyond this population is unknown.
  • The public repository provides figure-level source data, not raw RNS recordings or window-level predictions.
  • FPR is the fraction of non-seizure windows classified positive. It is not daily alert count, stimulation burden, calibration, or clinical benefit.
  • No uncertainty interval can be estimated around the interpolated participant values from the released ROC points alone.
  • The repository does not include an explicit license file. This page computes a minimal derived view and links to the source rather than redistributing the raw dataset.
